The tutorial focuses on how information about direction, distance, motion, and obstacles can be translated into meaningful vibration patterns.

Tutorial Overview

How does a visual scene become a vibration?

A camera provides visual information about the surrounding environment. An embedded system interprets that information, estimates spatial relationships, and selects a haptic signal that communicates direction, distance, or urgency.
